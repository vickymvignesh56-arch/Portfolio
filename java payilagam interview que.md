4\. What are the differences between C++ and Java?





C++ and Java are both object-oriented programming languages, but they have some major differences.

 First, C++ is platform-dependent because it is compiled into machine code, while Java is platform-independent since it runs on the JVM.

 Second, in C++ memory management is manual, using new and delete, whereas in Java memory is handled automatically by the Garbage Collector.

 Third, C++ supports pointers and multiple inheritance, but Java does not allow direct pointers and multiple inheritance;

 instead, it uses interfaces. Also, C++ allows operator overloading , while Java doesn’t support operator overloading.

 Finally, C++ is mostly used for system-level programming, game engines, and high-performance applications,

 whereas Java is widely used for enterprise applications, Android development, and web-based solutions.

5.Features of Java?





Java has several important features. First, it is platform-independent because of the JVM,

 which means “write once, run anywhere.” Second, it is object-oriented, so it supports concepts like inheritance,

 polymorphism, and encapsulation. Third, Java provides automatic memory management through Garbage Collection.

 Fourth, it is simple, secure, and robust, making it reliable for large applications. Java also supports multithreading,

 which allows multiple tasks to run at the same time, and it has a rich set of libraries and APIs. Finally,

 Java is distributed and portable, so it can be used for network-based and cross-platform applications.

 The architecture of Java?



The architecture of Java is based on the Java Virtual Machine (JVM). When we write Java code, it is compiled by the Java compiler into platform-independent bytecode. This bytecode is not machine-specific and can run on any operating system that has a JVM. The JVM interprets or executes the bytecode and also performs tasks like memory management, garbage collection, and security checks. This architecture allows Java to be portable, secure, and robust.

What are JDK, JVM, JRE, and JIT?





JVM (Java Virtual Machine):



\* What it is: The heart of Java's platform independence. It's an abstract machine that

provides a runtime environment in which Java bytecode can be executed.



• JRE (Java Runtime Environment):



\* What it is: A software package that provides the minimum requirements for running

a Java application. It contains the JVM along with the necessary Java class libraries and supporting files.









JDK (Java Development Kit):



\* What it is: A complete software development environment for developing,

compiling, and running Java applications.

 Rules for Identifiers in Java?



Identifiers in Java are the names given to variables, methods, classes,

or other user-defined elements. They are used to identify these elements in the program.

For example, in int age = 25; the word age is an identifier. Java identifiers must follow rules: they cannot be keywords, must begin with a letter, dollar sign, or underscore, and cannot contain spaces or special characters. They are also case-sensitive.



🔑 Rules for Identifiers in Java



* Must start with a letter (A–Z or a–z), underscore (\_), or dollar sign ($).



* Can contain letters, digits, underscores, and dollar signs.



* Cannot start with a digit.



* Cannot be a Java keyword (like class, int, static).



* Identifiers are case-sensitive (Age and age are different).



* No spaces or special symbols allowe
